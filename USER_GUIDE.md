# User guide

Sign in with the email account. If the local lock is enabled, confirm your fingerprint, or the phone pattern, when the app returns from the Home screen. That check does not replace the Supabase session.

## Money

Add a wallet, then an expense or an income. A transfer moves money between two wallets of the same currency and is not counted as income or spending. The Home cards say "This month, excluding transfers and refunds." Voiding a transaction keeps the row and removes it from the totals.

## Plan

Open Plan for budgets, goals, investments, the assistant, and Financial Studio.

Budgets compare spending in the selected week or month with the limit. Goals accept virtual contributions and do not move wallet money. Investment prices are manual. The screen marks them as not a live market and not advice.

Financial Studio shows the deployed model response first, then thirty on-device cards. An experimental status is not a validated prediction.

Ask the assistant in everyday French, English, Arabic, or Tunisian Latin, including spelling mistakes. It uses your recorded transactions, wallets, budgets, and goals. A broad word such as "food" asks which real category to use when several match. A savings answer is a simulation and never removes more than you actually spent in a category. It will not answer with zero while loading. No remote language model is configured, so the calculation stays on the phone. A draft transaction, budget, or goal is saved only after you confirm it.

## Receipts

Scan or pick a photo. Check the amount, date, merchant, and category, then confirm. Arabic text is flagged because the on-device reader uses Latin script.

## Account

Profile edits the name, phone, and bio. Sign-out closes the session. Delete account asks for the confirmation word. Until the server function is installed, that action stops and deletes nothing.
